# 🚗 DriveNow – Car Rental Website

## 📌 About the Project

DriveNow is a responsive car rental website developed using HTML, CSS, and JavaScript. It provides a simple and user-friendly interface for exploring rental cars, selecting drivers, and calculating estimated rental costs.

## ✨ Features

- Responsive navigation bar and homepage
- Car listings with images and rental prices
- Filter cars by location and vehicle type
- Car booking popup
- Self-drive and driver-assisted rental options
- Driver selection
- Automatic rental price calculation
- Customer contact form
- Responsive layout for desktop, tablet, and mobile devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all image paths are correct.
4. Open `index.html` in a browser or use the Live Server extension in VS Code.

## 🎯 Project Objective

The objective of this project is to practise frontend web development and create an interactive car rental interface using HTML, CSS, and JavaScript.
